# Mini Projects

A curated set of small projects and experiments created while learning HTML, CSS, JavaScript, Tailwind, Python, React, Node.js, and Rust. It also includes a few academic or practice code pieces.

## Projects

- [Aura](https://github.com/Om005/Mini-Projects/tree/main/Aura): Full-stack auth app with Next.js client and Node.js server.
- [Desktop-Assistance](https://github.com/Om005/Mini-Projects/tree/main/Desktop-Assistance): Python desktop helper scripts.
- [First-animated-web](https://github.com/Om005/Mini-Projects/tree/main/First-animated-web): Simple animated web page.
- [Layers-clone](https://github.com/Om005/Mini-Projects/tree/main/Layers-clone): UI layout clone.
- [LDPC-Codes](https://github.com/Om005/Mini-Projects/tree/main/LDPC-Codes): MATLAB scripts and resources for LDPC 5G-NR coding.
- [Learning-Rust](https://github.com/Om005/Mini-Projects/tree/main/Learning-Rust): Rust learning exercises and examples.
- [Music-Player](https://github.com/Om005/Mini-Projects/tree/main/Music-Player): Web-based local music player.
- [Netflix-Clone](https://github.com/Om005/Mini-Projects/tree/main/Netflix-Clone): Frontend UI clone.
- [Password-Manager](https://github.com/Om005/Mini-Projects/tree/main/Password-Manager): Vite-based React app with backend.
- [Terminal](https://github.com/Om005/Mini-Projects/tree/main/Terminal): Terminal-style web UI and experiments.
- [Todo-List](https://github.com/Om005/Mini-Projects/tree/main/Todo-List): Vite-based React todo app.
- [Track_version_control](https://github.com/Om005/Mini-Projects/tree/main/Track_version_control): Basic Rust based version controll system.
- [Winter_Of_Code_1](https://github.com/Om005/Mini-Projects/tree/main/Winter_Of_Code_1): Python practice problems and exercises.
- [Winter_Of_Code_2](https://github.com/Om005/Mini-Projects/tree/main/Winter_Of_Code_2): Basic web IDE where user can run and share their programming laguage codes.

## Notes

- Each folder is self-contained and may have its own README.
- Some projects require installing dependencies before running.

## Quick Start

1. Open a project folder.
2. Follow its README (if present).
3. If no README exists, check package files or entry points:
	- Web: `index.html`
	- Node/React: `package.json`
	- Python: `.py` files
	- Rust: `Cargo.toml`
